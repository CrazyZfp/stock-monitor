通知模板

「全局模板」对所有市场生效；各市场模板留空则继承全局，填入内容则该市场使用专属模板覆盖全局。每个市场仅显示其支持的通知类型。可写多行，每行一个模板随机选用；不存在的占位符会导致保存失败。

查看占位符说明
占位符说明可用类型备注
{name}官方股票名称全部不含昵称
{nickname}昵称全部未设置时回退到 {name}
{price}当前价格全部格式如 19.80
{threshold}触发阈值price_high / price_low单档绝对价格；其他类型为空
{daily_change}当日涨跌幅全部基于昨收的当日涨跌百分比，格式如 +2.50%
{speed_change}涨速surge_up / surge_down涨速窗口内的涨跌百分比，格式如 +2.50%
{retracement}回撤百分比retracement从最近峰值回落的百分比，格式如 -3.00%
{bounce}反弹百分比bounce从最近谷值回升的百分比，格式如 +3.00%
{time}涨速窗口（分钟）全部取自股票配置的"窗口/分"字段
{tier_index}档位序号 (1, 2, 3…)daily_up / daily_down当日涨跌百分比多档中的第几档
{tier_threshold}档位阈值daily_up / daily_down该档位的涨跌百分比，格式如 5.00%
{peak_price}回撤前峰值retracement最近一次突破后达到的最高价
{valley_price}反弹前谷值bounce最近一次跌破后达到的最低价
{t_type}做T操作类型t_sell / t_buyS 表示先卖后买，B 表示先买后卖
{t_price}做T事件价格t_sell / t_buy添加 S/B 事件时记录的价格
{t_threshold}做T百分比t_sell / t_buy取自股票配置的做T阈值，格式如 3.00%
{t_quantity}做T数量t_sell / t_buy添加 S/B 事件时填写的交易数量（股票以手为单位），未填则为空
{position_cost}持仓成本profit / loss资产配置的持仓成本价，格式如 19.80
{profit_pct}盈亏百分比profit / loss现价相对持仓成本的盈亏百分比（合约已按方向和倍率折算），格式如 +3.00%
{direction}合约方向profit / loss合约方向，多 或 空（股票/基金为空）
{leverage}合约倍率profit / loss合约杠杆倍率，如 10倍（未填则为空）
{limit_price}涨/跌停价limit_up / limit_down 等涨停或跌停价，格式如 11.00
{sealed_lots}封单手数涨跌停相关封单量（手，1手=100股），带千分位如 100,000
{sealed_amount}封单金额涨跌停相关封单金额（万元），如 11,000.00
{seal_min_lots}封单不足阈值limit_up_low_seal / limit_down_low_seal取自股票配置，手
{seal_eta_seconds}预计耗尽秒数limit_up_exhaust / limit_down_exhaust按近期平均消耗速度预测的剩余秒数
